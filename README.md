# 3D lamp by agent

ISSAY pendant lamp, run through [alifs-3d-agent](https://github.com/julfikerhaider2001/alifs-3d-agent).

| Folder | What |
|---|---|
| `issay-pendant-lamp/` | Print files: E26/E27 and E14 versions (STL) |
| `output/fit/` | Fit check against the E27 holder |
| `output/renders/` | Blender scene and Cycles renders |
| `output/posters/` | Feed, story and Facebook posters plus the HTML source |
| `output/production/` | Production sheet: 84 g PLA Matte, 6 h 37 min on an A1, cost ৳448, suggested price ৳630 |
